🧮 Web Calculator (HTML, CSS & JavaScript)

A fully functional, browser-based calculator built using HTML, CSS, and JavaScript. This project is perfect for beginners looking to learn frontend development, DOM manipulation, and basic JavaScript logic. The calculator provides a clean interface for performing basic arithmetic operations like addition, subtraction, multiplication, and division.

🌟 Features
Basic Arithmetic Operations: Perform +, -, ×, ÷ calculations with ease.
Responsive Design: Works on desktop and mobile screens.
Interactive UI: Buttons highlight on hover and display inputs and results in real-time.
Easy to Customize: Modify colors, button shapes, and layout through CSS.
Lightweight & Fast: No external libraries needed, runs entirely in the browser.

🚀 How It Works
Open the index.html file in any modern web browser.
Click the number buttons to input values.
Use the operation buttons (+, -, ×, ÷) to perform calculations.
Press = to get the result.
Use C or AC to clear the display.

🛠 Technologies Used
HTML5 – Provides the structure of the calculator.
CSS3 – Styles the buttons, layout, and interactive effects.
JavaScript – Handles all the calculation logic and updates the display dynamically.

💡 Learning Outcomes
Understand HTML element creation and layout.
Learn CSS styling and responsive design techniques.
Practice JavaScript event handling, functions, and logic.
Gain experience building interactive web applications.
